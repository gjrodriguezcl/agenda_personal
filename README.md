# 📚 Agenda Personal

Una aplicación de gestión de agenda desarrollada en Python que permite administrar tareas, eventos, cumpleaños y feriados con soporte para repeticiones y seguimiento de progreso.

## ✨ Características

- **Tareas normales y repetitivas** con múltiples frecuencias (diaria, semanal, quincenal, mensual, bimestral, trimestral, cuatrimestral, semestral, anual)
- **Sistema de ocurrencias** que permite marcar cada repetición como completada individualmente
- **Eventos** con lugar y fecha
- **Cumpleaños** con cálculo automático de edad
- **Feriados** con opción de recurrencia anual
- **Seguimiento de progreso** con estadísticas de tareas repetitivas
- **Búsqueda y filtros** por tipo de item y estado
- **Recordatorios** diarios y de los próximos 7 días
- **Edición completa** de cualquier item
- **Exportación** a CSV y JSON
- **Dos interfaces**: línea de comandos (CLI) e interfaz gráfica (GUI con Tkinter)

## 📋 Requisitos

- Python 3.8 o superior
- Tkinter (incluido en la instalación estándar de Python)
- No requiere librerías externas adicionales
